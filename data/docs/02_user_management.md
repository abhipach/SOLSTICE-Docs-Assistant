# User Management and Roles

## Inviting users
Invite users by email from Users, then Invite. Invitation links expire after 7 days and can be resent. To add many people at once, upload a CSV with up to 1,000 rows per upload.

## Roles and permissions
There are five roles. Owner has full control including billing and security. Admin manages courses and users but not billing. User Manager can invite, deactivate and send password resets for users. Report Viewer has read-only access to reports. Learner can only take assigned courses. Each person has exactly one role.

## Groups
Groups let you assign courses and filter reports for a set of learners, such as a department. A user can belong to many groups. Groups can be created manually or populated from a CSV.

## Deactivating and deleting users
Deactivating a user blocks sign-in but keeps their completion history and frees up their seat at the next billing cycle. Deleting a user is permanent after a 30-day grace period during which an Owner can restore them.
